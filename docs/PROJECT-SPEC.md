# 타각(Tagak) 프로젝트 명세

타각(Tagak)은 한메타자교실의 연습 경험을 오늘날에 맞게 재해석한 로컬 타자 연습 앱이다. 한글 우선·키보드 중심으로 자리, 낱말, 한 줄, 짧은 글과 긴 글을 오프라인에서 연습한다. 구현 순서와 현재 상태는 [SPEC.md](SPEC.md), 개발자용 구조 설명은 [ARCHITECTURE.md](../ARCHITECTURE.md), 버전별 변경 이력은 [CHANGELOG.md](../CHANGELOG.md)에서 확인한다.

제품 이름은 한국어 `타각`, 영어 `Tagak`으로 쓴다. 화면 헤더는 인터페이스 언어에 맞추며, 브라우저 제목은 `타각 — Tagak`이다. 한 줄 소개는 한국어 UI에서 `키보드 중심의 로컬 타자 연습 프로그램`, 영어 UI에서 `A keyboard-first, local typing practice app.`이다. 프로젝트 고유명사는 이 표기를 따르며, 일반적인 `타자 연습`과 디자인 배경을 설명하는 `레트로`는 그대로 쓸 수 있다.

## 참조 경험과 제품 범위

Windows Chrome에서 참조 앱의 메뉴 이동, 설정 항목의 방향키 이동, 한 줄 제출, 짧은 글의 줄 이동을 직접 확인했다. 메뉴는 가운데에 간결하게 배치되고 선택한 행을 강조한다. 여러 화면에서 방향키와 Enter로 앞으로 가고 Esc로 한 단계씩 돌아갈 수 있다. [온라인 타자교실](https://typing.zidell.me/) · [에듀베이지 소개](https://www.edubeige.com/post/typing-zidell)

| 참조 앱에서 확인한 동작 | 프로젝트에서 적용할 경험 |
| --- | --- |
| 한 줄은 분류를 고르면 입력창에 초점이 간다. 제시문 아래에 입력이 표시되고 오타 위치에 표시가 붙는다. 일치한 문장을 Enter로 제출하자 같은 화면에 새 문장이 나오고 직전 속도가 남았다. | 첫 구현부터 제시문·입력·점수를 한곳에 둔다. A01 결과에서는 Enter로 바로 재시도한다. 여러 문장이 생기는 A02에서는 화면을 떠나는 단계 없이 다음 문장으로 이어간다. |
| 짧은 글과 긴 글 목록은 제목과 글자 수를 보여준다. 짧은 글 연습에서 줄을 제출하자 완료한 줄이 남고 다음 줄의 입력창에 초점이 갔다. | A03에서 제목과 분량을 보고 글을 고른다. 연습 중에는 현재 줄과 전체 진행을 알 수 있고, 제출할 때 입력 초점이 다음 줄로 이동한다. |
| 화면 하단의 단문 최고 속도는 제출 직후 갱신됐고 새로고침하면 초기화됐다. | A04에서 직전 연습과 비교할 수 있게 하고, 최근 완료 기록은 같은 브라우저에 보존한다. |
| 타자게임 목록과 첫 게임의 난이도 선택 화면이 있었다. 연습장은 제시문 없이 입력할 수 있었고, 환경설정에는 언어·색상·서체·효과음 항목이 있었다. | A07은 독자적인 시간 제한 도전으로 만들고 A08은 제시문 없는 자유 입력 공간을 제공한다. A12에서 시작 메뉴의 키보드 접근 가능한 환경설정으로 언어·크기·테마·언어별 글꼴·효과음을 고른다. |
| 화면 하단에 `화면저장 (Ctrl+S)`가 항상 보인다. | A09에서 현재 앱 화면을 PNG로 내려받는다. 버튼과 Windows 기준 `Ctrl+S`를 제공한다. |

자체 제목과 화면 구성을 사용한다. 짙은 배경, 호박색 강조색, 고정폭 계열 제목으로 터미널 분위기를 살리고 연습 카드를 화면의 중심에 둔다. 핵심 조작과 점수가 눈에 띄도록 화면을 구성한다. 예문과 게임 콘텐츠는 직접 작성하거나 사용 조건이 확인된 자료를 사용한다.

| 범위 | 사용자에게 보이는 동작 |
| --- | --- |
| 첫 슬라이스 | 로컬 주소를 열고 한글 단문 한 편을 연습한다. 입력 중 오타, 정확도, 타자 속도를 확인하고 완료 후 최종 결과를 본다. Enter로 같은 문장을 바로 다시 연습하거나 메뉴로 돌아간다. |
| 초기 제품 | 한글 자리·낱말·한 줄·짧은 글·긴 글 연습을 제공한다. 영문은 낱말·한 줄·짧은 글·긴 글을 제공한다. 한 줄은 같은 언어에서 여러 문장을 이어서 연습할 수 있다. 같은 브라우저에서 최근 결과와 설정을 이어서 본다. |
| 추가 연습 | A07 30초 낱말 도전, A08 자유 입력 연습장, A30 베네치아 타자 게임을 제공한다. 자유 입력은 점수와 앱 기록을 만들지 않고, 나갈 때 입력 내용을 버린다. 베네치아는 고전 DOS 게임 분위기에서 영감을 얻은 비공식 타각판 재구성이며, 원작 실행 파일·이미지·폰트·사운드·단어 DB를 포함하지 않는다. 1~14레벨 탑 방어 게임으로 100~1000 CPM 지수 목표, 레벨별 득점, 플레이 실적 기반 시작 레벨 추천, 로컬 Top 10을 제공한다. |
| 글 연습 단위 (A19) | 한 문장 연습은 `한 줄`로 부른다. 200~2000자 안팎의 `짧은 글`과 2000자 내외의 `긴 글`은 문학·비문학·기술·생활·서브컬쳐 장르에서 고르며, 줄바꿈된 5줄 묶음으로 보여 주고 한 줄씩 제출한다. 연습 자료와 도전 낱말은 코드와 분리한 JSON 애셋에서 읽는다. |
| 자료 출처 (A20) | 직접 작성한 원문과 함께 위키문헌·위키백과(CC BY-SA 4.0), 법령(저작권법 제7조)처럼 사용 조건이 분명한 자료를 쓴다. 복제한 자료는 애셋에 저자·출처·라이선스·URL을 남기고 글 고르기 목록에서 표시한다. |
| 화면 저장 (A09) | 버튼이나 Windows 기준 `Ctrl+S`로 현재 앱 화면을 PNG로 내려받는다. 화면에 보이는 입력과 점수를 포함하며, 연습장에서 저장을 요청하면 직접 입력한 내용도 이미지에 들어간다. 앱은 자동 저장·전송하지 않는다. |
| 색상 테마 (A10) | 표시 설정에서 현재 색상 테마를 바꾼다. 기본 터미널 테마를 유지하면서 밝은 종이 테마를 선택할 수 있고, 선택은 같은 브라우저에 보존된다. |
| 연습 글꼴 (A11) | 고딕과 명조 중 연습 글꼴을 선택한다. 글꼴은 제시문, 입력창, 글 묶음 문맥, 자유 입력 편집기, 도전 낱말에 적용하고 선택을 같은 브라우저에 보존한다. 시스템 글꼴만 사용해 오프라인 실행을 유지한다. |
| 환경설정 (A12) | 시작 메뉴에서 키보드로 설정 화면에 들어간다. 진행 화면에서도 환경설정 바로가기를 쓸 수 있으며 돌아오면 입력 상태를 유지한다. 인터페이스 언어와 연습 언어를 각각 바꾸고, 시작 메뉴와 글 자료는 선택한 연습 언어 자료만 보여준다. 진행 중에는 연습 언어를 잠그고, 메뉴로 돌아가 바꾼다. 글꼴은 한국어/영어별로 따로 기억한다. 효과음은 기본 꺼짐이며, 연습 단위 완료음은 단위가 끝날 때만 한 번 울리고 (A23), 베네치아 게임 피드백도 같은 설정으로 제어한다. |
| 키보드 설정·포커스 복귀 (A18) | 온라인 타자교실처럼 설정을 한 줄씩 강조하는 메뉴로 표시한다. ↑/↓로 항목을 이동하고 ←/→ 또는 Enter/Space로 선택 값을 바꾼다. 초기화 동작도 같은 목록에서 Enter/Space로 실행한다. 다른 브라우저 탭이나 창에서 앱으로 돌아오면 마지막으로 사용한 앱 컨트롤에 초점을 복구한다. |
| 타자 속도 단위 (A13) | 환경설정에서 한국어·영어의 속도 단위를 각각 고른다. 기본값은 한국어 cpm(분당 타수), 영어 wpm(분당 단어 수)이다. 결과·기록·이전 기록 비교는 연습 언어의 단위를 쓰며, wpm은 원시 cpm을 5로 나눠 표시한다. 입력 중에는 정확도만 보여주고 속도는 연습 단위가 끝날 때 같은 단위로 보고한다(A23). |
| 한글 한 줄 제출 (A14) | 한글 한 줄 자료에서 문장 끝 문장부호를 없앤다. 한글 한 줄에서 제시문을 다 입력한 뒤 Enter 또는 조합 중이 아닌 Space로 제출한다. |
| 전 모드 Space 제출 (A15) | 낱말·한 줄·글의 각 줄·도전 낱말에서 요구 입력을 마친 뒤 Space로 제출한다. 입력 중의 Space는 제시문 공백으로 입력한다. IME 조합을 끝내는 Space는 글자를 확정한 뒤 필요한 공백 삽입 또는 제출로 한 번 처리한다. |
| 한글 타수 속도 (A16) | 한국어 CPM은 완성 글자 수가 아니라 입력에 남아 있는 두벌식 타수를 기준으로 계산한다. 정확도는 글자 단위로 별도 표시하며, 영어 WPM은 현재 계산을 유지한다. |
| 후속 범위 | 설치형 패키지와 다른 자판 배열은 실제 수요가 생길 때 검토한다. |

앱의 실행과 연습은 오프라인을 기본으로 한다. 계정, 서버 동기화, 공개 순위, 원격 측정, 외부 폰트와 CDN은 초기 범위에서 제외한다. 데스크톱과 물리 키보드를 우선한다.

## 화면과 사용 흐름

| 화면 | 사용자 동작과 피드백 |
| --- | --- |
| 시작 메뉴와 자료 선택 | 첫 항목에 초점을 두고 선택 상태를 눈에 띄게 표시한다. 메뉴 안에서는 위·아래 방향키 또는 Tab과 Shift+Tab으로 이동하고 Enter나 클릭으로 선택한다. 긴 목록은 `Home`·`End`로 처음·끝 항목으로, `PageUp`·`PageDown`으로 여러 항목을 건너뛴다. 하위 목록에서 뒤로 가면 직전에 선택한 상위 항목에 초점을 돌려준다. |
| 연습 | 진입과 줄 전환 직후 이름이 있는 입력창에 초점을 둔다. 제시문, 현재 위치, 오타를 보여주고 확정 입력이 바뀔 때 정확도를 갱신한다. 속도는 입력 중에 갱신하지 않고 낱말·줄·묶음이 끝나는 시점에 한 번 보고한다. 정확·오타는 색과 별도의 밑줄 또는 표시로 구분한다. 낱말·한 줄·글의 각 줄은 끝까지 입력한 뒤 Enter 또는 Space로 제출하며, 입력 중 Space는 공백으로 남긴다. 뒤로 가기 버튼과 조합 중이 아닐 때의 Esc는 직전 메뉴나 자료 목록으로 돌아간다. |
| 한 줄 이어서 연습 (A02) | 한 문장을 제출하면 같은 화면에 직전 문장의 정확도와 속도를 남기고 바로 다음 문장을 입력하게 한다. 현재 점수와 직전 점수의 이름을 구분한다. 제출마다 독립된 연습 한 건을 완료하고 다음 문장에서 입력과 타이머를 새로 시작한다. 목록의 마지막 문장 다음에는 첫 문장으로 돌아간다. |
| 여러 줄 연습 (A03, A19) | 전체 묶음 수와 현재 묶음을 표시한다. 짧은 글·긴 글은 너비에 맞춰 줄바꿈한 5줄을 한 묶음으로 보여 주고, 현재 줄을 강조하며 이미 제출한 줄은 완료 표시한다. 입력창은 현재 줄 하나에 연결하고, 5번째 줄을 제출하면 다음 묶음으로 넘어간다. 묶음의 마지막 줄을 제출하면 그 묶음의 정확도·속도를 남기고 다음 묶음은 새 속도 구간으로 시작한다(A23). |
| 결과 | 완료 요약에 초점을 옮긴다. 요약에 초점이 있을 때 Enter로 이어서 연습하고 Esc로 돌아갈 수 있다. 낱말 연습 결과의 Enter는 다음 낱말, 그 밖의 결과에서는 같은 연습을 다시 시작한다. 정확도, 연습 언어에 맞는 속도 단위, 경과 시간과 함께 다시 연습, 돌아가기 버튼을 제공한다. 돌아갈 때 연습을 골랐던 위치의 초점을 복원한다. |
| 베네치아 게임 (A30) | 시작 레벨 1~14를 키보드로 고르고, 자유 입력에서 보이는 낱말을 맞혀 낙하 단어를 제거한다. 일반 단어는 12블록 탑을 손상하고 특수 단어는 타각판 효과를 발동한다. 일반 낱말 상단이 빨간 충돌선(판 높이 75%)에 도달하면 탑 블록 하나가 손상된다. 한 게임 안에서 이미 등장한 낱말은 그 레벨의 후보 낱말을 모두 사용하기 전에는 다시 나오지 않는다. 낱말 상자는 한 줄로 표시한다. 1~13레벨은 일반 단어 할당량과 화면 내 단어가 정리되면 승급하며, 14레벨은 계속 점수를 쌓는다. 7·11·13레벨부터 추가 낱말 묶음을 차례로 연다. 탭 비활성화·환경설정 진입 시 게임 시간을 멈춘다. 게임 종료 결과에서 플레이 요약과 같은 브라우저의 Top 10을 확인한다. 게임 소리는 환경설정 효과음 토글을 따르고 기본 무음이다. |
| 자유 입력 연습장 (A08) | 빈 여러 줄 편집기를 열고 원하는 내용을 입력한다. Enter는 줄바꿈으로 동작한다. 점수·결과·연습 기록은 만들지 않는다. Esc 또는 메뉴 버튼으로 나가면 내용을 버리고, 다시 열면 빈 편집기가 된다. 일반 편집기처럼 붙여넣기를 허용한다. 사용자가 A09 화면 저장을 직접 선택하면 현재 보이는 입력이 PNG에 포함된다. |
| 시작 메뉴와 환경설정 (A12, A18) | 한국어 또는 영어 UI를 선택한다. 연습 언어는 별도로 바꾸며 기본값은 둘 다 한국어다. 언어 선택과 상관없이 연습장·기록·환경설정으로 갈 수 있고, 자료 목록은 선택한 연습 언어로 좁힌다. 크기·테마·언어별 글꼴·효과음 설정은 같은 브라우저에 보존한다. 설정은 한 줄씩 강조하는 메뉴로 보여주며 ↑/↓로 항목을 이동하고 ←/→ 또는 Enter/Space로 값이나 초기화를 조작한다. 다른 브라우저 탭이나 창에서 돌아오면 앱에서 마지막으로 사용한 컨트롤에 초점을 복원한다. |
| 기록 | 최근 완료 결과를 모드별로 확인한다. 결과 화면에서 같은 모드와 언어의 직전 기록과 비교한다. 한국어와 영어 기록은 각각 선택된 속도 단위로 표시한다. 기록 지우기를 누르면 확인이 열리고 초점은 ‘취소’에 놓이며, 취소하면 원래 기록 지우기 버튼으로 돌아간다. 로컬 기록을 지울 수 있고, 저장에 문제가 생겨도 현재 연습과 결과 확인은 계속된다. |

A30의 시각 참고 자료에는 DOS판 화면 사진과 게임 개요가 있다([DOSBox 화면 기록](https://sevensign.net/m/5587), [화면·규칙 개요](https://seore.org/w/%ED%95%9C%EB%A9%94%ED%83%80%EC%9E%90%EA%B5%90%EC%82%AC)). 확인한 범위는 물 위의 12블록 탑, 하늘에서 떨어지는 단어, 노란 특수 단어다. 이를 시각적 개념으로만 참고하고 세부 규칙·수치를 확정된 원작 사양으로 취급하지 않는다.

브라우저 확대 200%에서 제시문, 입력창, 주요 버튼을 모두 사용할 수 있어야 한다. 텍스트와 초점 표시를 읽기 쉽게 만들고, 자주 바뀌는 입력 상태와 별도로 완료·저장 상태를 보조 기술에 알린다. 연습 조작 단축키는 관련 화면에 한정한다. 화면 저장용 `Ctrl+S`는 앱 화면 안에서만 처리하며 IME 조합 중에는 가로채지 않는다.

초기 자리 연습은 두벌식 영문 물리 키 26개를 표시하고 기본자리에서 손가락을 옮기는 9회의 예제로 시작한다. 시작 메뉴는 두벌식 자리 연습을 맨 위에 두고, 선택한 연습 언어의 낱말·한 줄을 그 아래에 놓는다. 연습 언어를 이미 고른 상태이므로 항목 이름에 `한글`·`영문`을 붙이지 않는다. 낱말은 한 건마다 결과를 보여주고 그 결과에서 `Enter`나 ‘다음 낱말’로 목록의 다음 낱말을 이어서 연습한다. 마지막 낱말 다음에는 첫 낱말로 돌아오며, ‘다시 연습’은 방금 끝낸 낱말을 반복한다. 연속 한 줄의 ‘연습 마치기’는 직전 문장의 결과를 보여준다.

홈 메뉴 이름 앞에는 종류를 나타내는 태그를 붙인다. 자리·낱말·한 줄·짧은 글·긴 글은 `[연습]`, 30초 낱말 도전과 베네치아는 `[게임]`, 연습장·최근 연습 기록·환경설정은 `[기타]`다. 인터페이스 언어가 영어이면 같은 규칙을 `[Practice]`·`[Game]`·`[Other]`로 적용한다. 태그는 홈 메뉴에만 붙이고 연습 결과 제목, 글 고르기 목록, 기록 필터의 모드 이름에는 붙이지 않는다.

짧은 글과 긴 글 목록에는 직접 작성한 한국어·영어 자료를 장르와 글자 수와 함께 제공한다. 글을 읽으며 연습할 수 있도록 5줄 묶음의 완료한 줄, 현재 줄, 다음 줄을 함께 보여준다. 목록의 글자 수는 원문의 문자소 수를 센다. 자료는 `src/content/assets/`의 JSON 파일에 두고 코드에서 검증해 읽는다.

### 명세를 구체화한 초기 가정

- 기본 인터페이스와 연습 언어는 한국어다. A12부터 인터페이스 언어와 연습 언어는 독립적으로 선택한다. 영어 연습에서는 영문 낱말·한 줄·짧은 글·긴 글을 노출하고, 한글 전용 자리·도전 자료는 숨긴다. 공통 연습장과 기록은 계속 사용할 수 있다.
- A12는 모든 조작 안내와 접근 가능한 이름을 영어로도 제공한다. 연습 글꼴은 언어별로 저장하고, 효과음은 기본 비활성화한다. 연습 완료음과 베네치아의 게임 피드백은 같은 설정을 사용한다.
- 첫 한 줄은 직접 작성한 저작권 부담 없는 문장으로 번들에 담는다. 60자 이내로 정하고, 입력 부담을 낮추면서 띄어쓰기와 문장 부호를 포함한 연습을 보여주기 위함이다.
- 짧은 글은 200~2000자, 긴 글은 2000자 내외로 직접 작성한 원문을 쓴다. 외부 자료를 추가할 때는 `license`와 `credit`에 사용 조건을 확인한 출처를 남기고 앱은 빌드 시 함께 번들해 오프라인 실행을 유지한다. 줄바꿈 폭은 한국어 24자, 영어 44자로 고정해 5줄 묶음의 경계가 새로고침과 기기 너비에 흔들리지 않게 한다.
- 외부 자료는 `license`와 `credit`(저자·출처·URL)을 애셋에 구조화해 기록하고, `original`이 아닌 자료는 `credit`이 없으면 읽지 않는다. CC BY-SA 4.0과 공공누리 제1유형의 출처 표기 의무는 비상업적 배포에서도 유지되므로, 글 고르기 목록에 저자·출처·라이선스를 함께 보여 준다. 현재 쓰는 출처는 한국어·영어 위키문헌(CC BY-SA 4.0), 한국어·영어 위키백과(CC BY-SA 4.0), 대한민국헌법 전문(저작권법 제7조)이다.
- 루트 `TEXT-LICENSES.md`가 모든 연습문의 출처·라이선스와 새 자료 추가 절차를 모은다. 이 문서는 콘텐츠 모듈에서 생성하며, `npm run text-licenses:update`로 갱신하고 `npm run test`가 애셋 메타데이터와의 일치를 검증한다(A24).
- 한글 입력에서 Enter는 먼저 조합을 확정하고 다시 눌러야 제출할 수 있다. IME의 이벤트 순서가 브라우저에 따라 다른 경우를 검증하고, 일반 영문 입력기의 Enter는 한 번으로 제출할 수 있게 한다.
- Node.js 기준선은 Vite가 지원하는 22.12.0 이상으로 설정한다. 이 범위에는 지원 중인 LTS인 22, 24, 26이 포함되며, Alpha 또는 Current 릴리스는 설치 요건으로 요구하지 않는다. [Node.js 지원 현황](https://nodejs.org/en/about/previous-releases) · [Vite 요구사항](https://vite.dev/guide/)
- 빌드 및 개발에는 npm 잠금 파일의 버전을 쓰고, 사용자 실행에는 의존성 설치를 요구하지 않는다.
- 입력 시간은 첫 확정 글자 입력부터 제출까지로 측정한다. 분당 글자 수의 초기 피드백은 1초 미만에서 `—`로 두고, 필요하면 짧은 연습 세션에서의 실제 사용 근거로 조정한다.
- 최신 데스크톱 브라우저의 텍스트 입력을 목표로 한다. 모바일 터치 자판, 오프라인 브라우저 캐시(Service Worker), 설치형 앱 패키징은 A01에 포함하지 않는다.

## 실행과 기술 선택

하나의 정적 웹앱과 루프백 실행기를 유지한다. 현재 제품 기준 환경은 Windows 11 + Chrome이다. A17에서 macOS Tahoe + Chrome 157의 특정 한국어 IME Space 동작을 실제 입력기로 확인했으며, Windows Edge와 macOS Safari 및 전체 macOS 호환성 검증은 후속 범위다. Linux Firefox와 IBus는 보조 환경이다. Windows 11 + Chrome에서 설치·빌드·실행 또는 기본 한글 연습을 막는 치명적 문제가 재현된 경우에만 현재 개발을 멈춘다. 로컬 배포물에는 빌드한 `dist/`와 Node.js 내장 HTTP·파일 모듈을 쓰는 `serve.mjs`를 함께 둔다. 지원되는 Node.js LTS를 설치한 컴퓨터에서 `node serve.mjs`로 시작하고 브라우저에서 `http://127.0.0.1:41793/`를 연다. 실행기는 해당 루프백 주소에만 바인딩하고 `dist/` 안의 정적 파일만 제공한다. 포트 사용 중이면 원인을 안내하고 종료한다. Vite가 주로 쓰는 개발·미리보기 포트와 주소를 분리해서 브라우저 저장소와 다른 앱의 Service Worker가 겹칠 가능성을 낮춘다. Node.js 준비 이후에는 추가 패키지 설치나 인터넷 연결 없이 실행한다.

## 구현 구조

아래 경로는 구현을 시작할 때 적용할 경계다. 기능이 들어오는 순서에 맞춰 디렉터리를 만든다.

| 위치 | 책임 |
| --- | --- |
| `src/domain/` | 연습 자료, 세션 타입, 상태 전이, 입력 비교와 점수 계산. 브라우저, React, 시스템 시각, 저장소를 직접 참조하지 않는다. |
| `src/app/` | 메뉴·설정·연습·결과의 전환과 기능 연결. 타입이 지정된 이벤트를 도메인에 넘기고 초점 이동·결과 저장을 실행한다. `useScreenCapture`는 저장 상태와 `Ctrl+S`·IME 경계를 관리한다. |
| `src/ui/` | React 화면과 접근 가능한 폼, 한글 입력을 받는 브라우저 어댑터, 결과 표시. 색상 테마와 연습 언어·글꼴은 문서 루트 data 속성과 CSS 사용자 정의 속성으로 적용한다. 화면 저장은 DOM을 PNG로 렌더링해 내려받고, 선택된 효과음은 브라우저 Web Audio로 생성한다. |
| `src/storage/` | 로컬 데이터 읽기·검증·변환·저장. 글자 크기, 색상 테마, 한국어·영어별 글꼴·속도 단위, 인터페이스·연습 언어와 효과음 설정을 보존한다. 베네치아 최근 30회·Top 10은 별도 규칙 버전 저장소로 관리한다. |
| `src/content/` | 안정적인 ID, 언어, 모드, 제시문, 출처를 담은 번들 콘텐츠. 연습 자료와 도전 낱말은 `assets/`의 JSON에서 읽어 경계에서 검증하고, 화면 문구와 형식 함수는 `interfaceText.ts`에 둔다. |

`키보드·IME → 확정된 입력과 경과 시각 → 순수 상태 전이 → 화면 갱신 → 완료 결과 저장 / 선택된 효과음`

화면 저장은 사용자가 버튼이나 `Ctrl+S`를 선택했을 때만 앱 루트를 PNG로 변환하고 브라우저 다운로드를 시작한다. 버튼과 저장 안내는 이미지에서 제외한다. 연습장 텍스트는 명시적으로 저장한 PNG에 포함되지만 앱 기록이나 네트워크로 보내지 않는다.

- `Lesson`은 모드 식별자로 구분한다. 자리 연습은 물리 키 목록, 한 줄과 낱말은 하나의 제시문, 짧은 글과 긴 글은 줄바꿈한 줄 목록을 담는다. 빈 목록과 빈 제시문은 콘텐츠를 읽을 때 거른다. 자리 연습은 대상 위치와 `KeyboardEvent.code`를 비교한다. 입력된 글자 대신 키 위치를 배우기 위한 모드이며 키 길게 누르기와 브라우저 단축키는 시도로 집계하지 않는다.
- 화면 상태는 메뉴, 자유 입력, 연습, 결과 중 하나다. 자유 입력은 편집 중인 텍스트가 화면 안에만 존재하며 나가면 폐기한다. 점수나 완료 기록을 만들지 않는다. 연습은 확정 텍스트가 비어 있는 시작 전 상태와 시작 시각이 있는 진행 상태를 구분한다. 재시도는 입력·계수·시각이 빈 새 세션을 열고, 결과에는 완료한 세션의 집계만 담는다.
- 운영체제의 IME가 조합 중인 텍스트는 편집기에 남긴다. 조합이 끝난 실제 입력값을 한 번만 반영한다. Firefox와 IBus처럼 조합 확정 뒤 같은 키 누름의 일반 Enter가 전달되는 경우를 처리하기 위해, 조합에 쓰인 단축키는 물리 키가 떼어진 후 다시 받는다. 확정 버퍼를 NFC로 정규화하고 `Intl.Segmenter`의 문자소 단위로 비교한다. [조합 종료 이벤트](https://developer.mozilla.org/en-US/docs/Web/API/Element/compositionend_event) · [문자소 분할](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Intl/Segmenter)
- 입력은 일반 편집과 Backspace를 지원한다. 붙여넣기와 끌어놓기는 연습 입력창에서 차단하고 이유를 표시한다. 제시문과 같은 길이 이상 입력하면 Enter 또는 Space로 완료할 수 있다. 미완성 입력 중 Space는 제시문 공백으로 남긴다. A15에서는 IME 조합 중 Space가 조합을 끝내면 완성된 글자를 반영한 뒤, 제시문이 남았을 때 공백을 한 번 넣거나 입력이 끝났을 때 제출한다. 조합 종료 키의 중복 이벤트는 무시한다. 제출 시 남은 오타도 결과에 반영해서 정확도를 확인할 수 있게 한다. 짧으면 입력을 보존하고 남은 길이를 안내한다. 짧은 글과 긴 글은 Enter 또는 Space로 현재 줄을 확정하며, 마지막 줄에서 세션을 완료한다.

### 점수 규칙

- 확정 입력을 위치별로 제시문과 비교한다. 정확도는 일치한 글자 수를 전체 입력 글자 수로 나눈 백분율이다. 초과 글자는 오타로 센다. 완료 전에 수정한 오타는 최종 정확도에 반영되지 않는다.
- 한국어 cpm은 제출 시 입력창에 남아 있는 글자의 두벌식 타수 합 × 60 ÷ 경과 초다. 예를 들어 `한`은 `ㅎ+ㅏ+ㄴ`으로 3타, `까`는 쌍자음 `ㄲ`이 1타여서 2타, `과`는 `ㄱ+ㅗ+ㅏ`로 3타, `값`은 `ㄱ+ㅏ+ㅂ+ㅅ`으로 4타다. 단모음과 기본 자음은 각각 1타, 이중모음과 겹받침은 2타, 쌍자음은 1타로 센다. 공백·문장부호와 그 밖의 입력 문자소도 각각 1타다. 오타나 초과 입력도 남아 있으면 타수에 포함하고 정확도는 완성 글자 일치율로 별도 계산한다. 지웠거나 수정한 입력 이력은 최종 문자열에 남지 않으므로 타수에 포함하지 않는다.
- 영어 cpm은 일치한 최종 입력 문자소 수 × 60 ÷ 경과 초다. wpm은 영어 cpm ÷ 5로 표시한다. 타자 속도 단위를 바꿔도 정확도 계산은 유지한다. 첫 확정 입력에서 시작해 제출 동작에서 멈춘다. 짧은 글과 긴 글은 각 줄의 첫 확정 입력부터 제출까지 시간을 재어 글 전체와 묶음에 누적하며, 줄을 제출한 뒤 다음 줄의 첫 입력 전까지의 전환·적응 시간은 제외한다(A24). 묶음 속도는 그 묶음에서 완료한 줄들의 입력 시간 합을, 연습 완료 결과의 속도는 글 전체에서 완료한 줄들의 입력 시간 합을 쓴다. 1초 미만은 `—`로 표시한다. 계산은 원래 정밀도를 유지하고 화면에서 정수로 반올림한다.
- 시간 경과는 화면 경계에서 `performance.now()`로 읽어 이벤트에 담는다. 완료 후 결과는 고정되며, 짧은 글과 긴 글에서는 먼저 확정한 줄을 다시 채점하지 않는다.
- 자리 연습은 올바른 키를 누르면 다음 위치로 넘어간다. 결과는 경과 시간과 올바른 시도를 전체 시도로 나눈 정확도를 보여준다.

### 로컬 기록과 실패 처리

고정 주소의 저장 데이터에 스키마 버전을 붙인다. 인터페이스·연습 언어와 효과음 설정, 언어별 속도 단위, 글자 크기, 색상 테마, 한국어·영어별 글꼴, 완료 기록은 각각 분리된 키에 둔다. 일반 연습 기록은 고유한 세션 ID로 중복을 피하며 최근 100회만 보존한다. 각 기록에는 세션·자료 ID, 완료 시각, 모드와 언어, 소요 시간, 완성 글자 점수와 언어별 원시 속도 수치를 담는다. 베네치아는 `tagak:venice:records`의 독립 규칙 버전에 최근 30회 플레이와 총점 Top 10을 보존하며 일반 연습 기록과 합치지 않는다. A16 이전의 한국어 기록에서는 타수 복원이 불가능하므로 기존 정확도·시간은 보존하고 이전 CPM은 표시하지 않는다. 영어 속도는 기존과 같은 문자 기준으로 표시한다. 연습의 입력 원문은 세션이 끝날 때 폐기한다. 자유 입력은 완료 기록이나 앱 저장값을 만들지 않는다. 화면 저장은 사용자가 직접 요청할 때만 PNG 파일을 내려받는다.

연속 한 줄은 제출한 문장마다 기록을 만든다. 결과로 이동하거나 메뉴로 돌아가는 동작은 이미 완료한 문장의 기록을 추가하지 않는다. 기록 지우기는 확인 버튼을 눌렀을 때 해당 브라우저의 연습 기록을 지운다.

환경설정은 홈 메뉴의 항목이며, 연습 중에도 화면 머리글의 바로가기로 열 수 있다. 홈 메뉴에서 들어가면 제목에 초점을 옮기고, Esc나 뒤로 버튼으로 돌아가면 환경설정 항목에 초점을 복원한다. 다른 화면에서 열면 돌아올 때 진행 상태와 입력을 유지한다. 연습 언어는 현재 연습과 결과 화면에서 잠그며 메뉴로 돌아가면 바꿀 수 있다. 크기·테마·글꼴·효과음은 연습 중 바꿔도 현재 입력과 점수를 유지한다. 메뉴는 방향키와 Enter를 제공해 마우스 없이도 설정을 찾고 바꿀 수 있다.

인터페이스 언어와 연습 언어는 독립 선택이며 기본값은 둘 다 한국어다. 영어 UI는 메뉴·연습·도전·기록·설정 화면의 조작 안내와 접근 가능한 이름을 번역한다. 영어 연습은 영문 낱말·한 줄·짧은 글·긴 글 자료를 노출하고 한글 전용 자리 연습·도전은 숨긴다. 자유 입력·기록·설정은 두 언어에서 공통으로 제공한다. 영어 연습과 한국어 UI 조합도 허용한다.

글자 크기는 기본·크게·아주 크게, 색상 테마는 터미널 야간·종이 밝음, 글꼴은 고딕·명조 중에서 고른다. 글꼴은 한국어와 영어에 별도로 저장하며, 첫 언어별 설정에서는 기존 공통 글꼴을 두 언어에 모두 이전한다. 글꼴은 제시문·입력 필드·글 묶음 문맥·자유 입력 편집기·도전 낱말에 적용한다. 메뉴·키보드 도식·점수에는 적용하지 않는다. 글꼴은 시스템 글꼴 스택만 사용하고 외부 파일을 불러오지 않는다. 영어 명조는 Georgia 계열, 한글 명조는 Batang 계열을 우선한다. A13은 속도 단위를 언어별 환경설정에 저장한다. 설정은 즉시 적용하고 다른 설정의 변경이나 초기화에 영향을 주지 않는다. 화면 저장 PNG도 현재 화면의 테마와 글꼴을 따른다.

효과음은 기본 꺼짐이다. 켰을 때 낱말·한 줄이 끝나거나 짧은 글·긴 글의 5줄 묶음이 끝나는 시점, 도전 낱말을 맞힌 경우에만 완료음을 재생한다(A23). 자리 연습은 기존처럼 마지막 키를 맞혔을 때 한 번 재생한다. 베네치아는 입력·정답·피격·게임 종료 피드백을 추가한다. 브라우저 Web Audio를 로컬에서 사용하며, 재생이 차단되거나 지원되지 않으면 소리 없이 계속한다.

속도 보고 시점도 연습 단위에 맞춘다. 입력 중 점수판은 정확도만 보여주고, 낱말·한 줄 제출 시 그 항목의 속도를, 짧은 글·긴 글에서는 5줄 묶음이 끝날 때 묶음 속도를 보고한다. 연습 완료 결과는 마지막 묶음이 아니라 글 전체 기준 속도를 보여준다. 30초 낱말 도전은 속도를 보고하지 않는다(A23).

여러 탭에서 동시에 완료해도 기록이 유실되지 않도록 저장 어댑터는 Web Locks로 읽기·수정·쓰기와 초기화를 직렬화한다. 기존 저장 키의 이전은 새 키 잠금 다음 구 키 잠금을 획득해 신·구 버전 탭의 저장과 경쟁하지 않게 한다. 새 키가 이미 있으면 그 값이 우선하고 원본은 보존한다. 빈 새 키만 검증된 구 데이터를 복사하고, 다시 읽어 확인한 뒤 완료 표식을 저장했을 때 구 키를 정리한다. 손상된 값과 쓰기 실패는 원본을 남기며, 초기화는 완료 표식을 먼저 저장해 열린 구버전 탭이 나중에 쓴 데이터가 다시 나타나지 않도록 한다. 잠금을 사용할 수 없으면 저장 실패와 같은 방식으로 안내한다. [Web Locks API](https://developer.mozilla.org/en-US/docs/Web/API/Web_Locks_API)

잘못된 데이터나 지원하지 않는 버전을 읽으면 기본 설정과 세션 메모리로 연습을 유지하고 원본 저장값을 보존한다. 쓰기에 실패하면 현재 결과를 보여주고 저장되지 않았음을 알린다. 사용자가 로컬 데이터 삭제를 명시적으로 선택하면 초기화할 수 있다. 이 키 이전은 동일한 브라우저 origin 안에서만 가능하다. 앱의 배포 호스트나 포트가 바뀌면 브라우저가 별도 저장소로 취급하므로 기존 값은 자동으로 옮겨지지 않는다.

### 30초 낱말 도전

규칙을 읽고 시작하면 30초 동안 한글 낱말 하나씩을 입력한다. 확정한 입력이 낱말과 일치한 상태에서 Enter 또는 Space를 누르면 한 개를 해결하고 다음 낱말이 열린다. 틀렸으면 입력을 수정해서 다시 제출할 수 있다. 도중에 중단하거나 시간이 끝나면 해결한 낱말 수와 경과 시간을 결과 화면에서 확인한다. 결과 화면에서도 Enter로 새로 시작하고 Esc로 메뉴에 돌아간다.

브라우저의 단조 시계로 마감 시각을 정한다. 낱말은 번들 순서대로 보여주고 마지막 낱말 뒤에는 첫 낱말부터 반복한다. 첫 도전 모드의 점수는 해당 결과 화면에서 확인한다. A06은 Windows 11 + Chrome 기준 환경을 확인한다. A17은 macOS Tahoe + Chrome 157에서 해당 IME 문제를 확인했으며, Windows Edge와 그 밖의 macOS 호환성 검증은 후속 범위다. 플랫폼 지원 표기는 실제 확인을 마친 환경에 맞춘다.

## 품질 기준

- 현재 수용 기준은 Windows 11 + Chrome이다. 새 프로필에서 로컬 실행과 한국어 입력부터 제출·결과 확인까지의 흐름을 점검한다. 실제 Microsoft IME 조합, 오프라인 프로필, 200% 확대 중 아직 확인하지 못한 항목은 [플랫폼 검증표](PLATFORM-VERIFICATION.md)에 증거 공백으로 기록한다. 검증 도구의 한계만으로 개발을 멈추지 않는다.
- Windows Edge와 macOS Safari의 호환성 검증은 후속 범위다. macOS Tahoe + Chrome 157에서 A17의 특정 IME 흐름은 확인했지만 전체 macOS 지원 확인으로 확대하지 않는다. Linux Firefox와 IBus는 보조 증거다. Windows 11 + Chrome에서 기본 연습 흐름을 막는 치명적 문제가 재현된 경우에만 해결 전까지 현재 슬라이스를 멈춘다.
- 자동 검증은 실제 코드 또는 런타임 동작이 바뀌는 슬라이스에 한해 변경에 맞춰 실행한다. 문서 변경은 링크, 체크리스트, 구현 상태를 대조한다. 지원 선언은 실제 확인한 환경에 맞춘다.
