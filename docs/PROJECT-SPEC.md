# 타각(Tagak) 제품 명세

타각은 한메타자교실의 향수를 담은 로컬 타자 연습 앱이다. 한글과 영어를 오프라인으로 연습하고, 연습 기록과 설정을 사용자의 기기에 저장한다. 주요 사용 환경은 macOS 14 이상 Apple Silicon과 Windows 11 x64 Tauri 앱이다. 브라우저 실행 경로는 개발과 대체 사용에 제공하며 데스크톱 지원을 대신하지 않는다.

프로젝트 이름은 한국어 `타각`, 영어 `Tagak`으로 쓴다. 사용자 안내는 제품 소개와 다운로드를, 이 문서는 현재의 사용자 동작과 규칙을, [ARCHITECTURE.md](../ARCHITECTURE.md)는 코드 경계와 설계 근거를 설명한다. 개발·릴리즈 명령은 [DEVELOPMENT.md](DEVELOPMENT.md), 플랫폼 증거는 [PLATFORM-VERIFICATION.md](PLATFORM-VERIFICATION.md), 이전 개발 기록은 [v1.0.0 명세](https://github.com/SaehwanPark/tagak/blob/v1.0.0/docs/SPEC.md)와 [CHANGELOG.md](../CHANGELOG.md)에 있다.

## 제품 범위와 메뉴

타각은 계정·서버·원격 측정·온라인 순위·자동 업데이트를 사용하지 않는다. 설치 후 네트워크 없이 연습할 수 있고 기록은 기기의 앱 또는 브라우저 저장소에만 남는다. 앱·브라우저의 저장소는 분리된다.

홈 메뉴는 `한 줄`, `짧은 글`, `긴 글`, `게임`, `환경설정` 다섯 항목이다. 게임 하위 메뉴에서 `30초 낱말 도전` 또는 `베네치아`를 시작한다. 최근 연습 기록, 데이터 백업·가져오기, 저작권·제3자 고지는 환경설정에서 연다. 기존 버전이나 백업에서 가져온 자리·낱말 기록은 볼 수 있지만 해당 연습을 새로 시작하는 메뉴는 없다.

인터페이스 언어와 연습 언어는 별도 설정이며 기본값은 둘 다 한국어다. 영어 연습에는 영어 한 줄·짧은 글·긴 글 자료가 표시된다. 두 게임은 한국어 낱말을 사용한다. 언어별 속도 단위와 글꼴도 독립 설정이다. 색상 테마는 다크 10개와 라이트 4개를 제공한다.

## 연습 흐름

### 한 줄

한국어와 영어 각각 100개의 한 줄 자료 중 하나씩 연습한다. 매 세션의 문장 순서는 새로 섞는다. 세션은 기본 20문장이고 5·10·20·30·50·75·100개 중에서 고를 수 있다. 각 줄은 끝까지 입력하고 제출하면 다음 줄로 이어진다. 결과는 제출한 줄의 정확도와 속도 통계를 요약한다.

### 짧은 글과 긴 글

한국어와 영어의 문학·비문학·기술·생활·서브컬쳐 자료 중에서 글을 고른다. 짧은 글은 대체로 200~2000자, 긴 글은 2000자 안팎이다. 본문 순서는 유지하고 화면에는 한 줄씩 입력할 수 있도록 5줄 묶음으로 보여준다. 제출한 줄은 완료 상태로 남고, 현재 줄에 초점이 유지된다. 묶음 속도는 다섯 줄 묶음이 끝날 때, 글 전체 속도는 완료 결과에서 보여준다.

줄의 시간은 첫 확정 입력부터 제출까지다. 설정 화면이나 앱 창 비활성 구간은 제외하지만 읽거나 생각한 시간은 포함한다. 줄을 제출한 뒤 다음 줄 첫 입력 전까지의 전환 시간은 포함하지 않는다. 묶음과 글 전체는 각 줄의 측정 시간을 합산한다.

### 게임

**30초 낱말 도전**은 한글 낱말을 차례로 입력하는 게임이다. 30초의 활성 시간은 환경설정이 열리거나 앱 창이 비활성화된 동안 멈추며 복귀 후 이어진다. 맞힌 낱말 수를 결과로 보여주고 CPM/WPM은 보고하지 않는다.

**베네치아**는 1~14레벨의 한글 낱말 탑 방어 게임이다. 준비 화면에서 시작 레벨을 고르거나 최근 최대 5회 플레이에서 성과가 확인된 최고 레벨의 중앙값보다 한 단계 높은 추천을 선택한다. 추천 성과는 해당 레벨에서 일반 낱말 10개 이상을 내고 80% 이상 맞혔을 때 인정한다. 목표 CPM은 `round(100 * 10 ** ((level - 1) / 13))`으로 레벨 1의 100에서 레벨 14의 1000까지 증가한다. 레벨마다 일반 낱말 20개를 처리하면 다음 단계로 넘어가며 14레벨은 계속 점수를 쌓는다. 후보는 단계별 낱말 길이와 최소 레벨에 맞춰 고르고 같은 게임에서 현재 단계의 후보를 모두 사용하기 전에는 낱말을 반복하지 않는다.

맞힌 낱말 점수는 두벌식 타수 × 10 × `10 ** ((level - 1) / 13)`을 반올림한다. 일반 낱말이 빨간 충돌선(보드 높이의 75%)에 닿으면 12블록 탑에서 블록 하나가 손상되고, 12개가 모두 손상되면 게임이 끝난다. 특수 낱말은 게임 안의 효과를 발동한다. 타자가 직접 맞힌 낱말만 점수를 얻고 연쇄 제거는 점수를 주지 않는다. 틀린 제출은 낱말이나 게임 진행을 바꾸지 않고 입력란을 비운 뒤 오답 안내를 유지한다. 게임은 설정·앱 창·탭 비활성화나 사용자 일시정지 중 멈춘다. 최근 30회 플레이와 별도 Top 10을 로컬에 보관하며 Top 10은 점수 내림차순, 동점이면 먼저 완료한 순서로 정렬한다. 이 게임은 고전 DOS 게임 분위기에서 영감을 얻은 비공식 재구성이며 원작의 실행 파일, 이미지, 글꼴, 사운드, 단어 데이터베이스를 포함하지 않는다.

## 입력과 키보드 접근

한 줄·글 연습에서 정확도는 확정된 입력과 제시문을 문자소 단위로 비교한다. 정확한 문자소 수를 입력 문자소 수로 나눠 계산하며 잘못된 글자와 초과 입력도 분모에 포함한다. 수정한 뒤 최종 입력에 남지 않은 문자는 결과에 세지 않는다. 붙여넣기와 끌어놓기는 연습 입력에서 막는다.

한글 IME 조합 중인 텍스트는 확정 입력과 분리한다. `Enter` 또는 `Space`로 조합을 끝내는 키는 그 동작만 수행하고 중복 키 이벤트도 채점·제출하지 않는다. `Enter`로 조합을 마치면 다음 Enter가 줄을 제출한다. `Space`로 조합을 마칠 때 제시문이 남아 있으면 공백 하나를 입력하고, 줄이 끝났으면 제출한다. 미완성 입력에서 누른 Space는 입력 중인 공백으로 남는다.

메뉴·목록은 방향키로 이동하고 Enter로 선택한다. `Home`/`End`는 처음·끝 항목으로, `PageUp`/`PageDown`은 보이는 목록 영역에 맞춰 이동한다. 설정은 ↑/↓로 행을 고르고 ←/→ 또는 Enter/Space로 값을 바꾼다. `Esc`는 이전 화면으로 돌아간다. 진행 중 제출한 줄이 있거나 현재 줄에 `min(10, 제시문 문자소 수)` 이상을 입력한 뒤 나가면 확인을 거친다. 종료를 확정하면 미제출 입력은 버리고 완료한 줄만 조기 종료 세션으로 보관한다. 조기 종료 세션은 하이스코어 대상이 아니다. 데스크톱 홈의 Esc는 앱을 종료하고 브라우저 홈에서는 종료 키로 동작하지 않는다.

홈의 `?` 도움말은 선택 사항이다. `s`는 환경설정, `r`은 최근 연습 기록을 연다. 화면 저장은 macOS `⌘S`, Windows·브라우저 `Ctrl+S` 또는 화면 버튼으로 요청한다. 입력창에 초점이 있거나 IME 조합 중, 키 반복 중에는 도움말·화면 이동 바로 가기를 실행하지 않는다. `Tab`/`Shift+Tab`으로 주요 컨트롤을 이동할 수 있고, 앱이 다시 활성화되면 마지막으로 쓴 유효한 컨트롤에 초점을 복원한다. 정확·오타 표시는 색과 밑줄을 함께 사용한다. 200% 확대와 큰 글자에서도 주요 입력과 조작을 유지한다. 완료·저장·오류 상태는 자주 바뀌는 입력 상태와 별도로 보조 기술에 알린다.

## 점수와 세션 통계

**한국어 CPM**은 완성 글자 수가 아니라 제출 시 입력창에 남은 글자의 두벌식 타수로 계산한다. 기본 자음과 단모음은 1타, 쌍자음은 1타, 이중모음과 겹받침은 2타다. 공백·문장부호와 다른 입력 문자소는 각각 1타다. 수정하거나 지워 남아 있지 않은 입력은 속도에 포함되지 않는다. 정확도는 글자 일치율로 별도 계산한다.

**영어 CPM**은 제시문과 일치한 입력 문자소 수, **영어 WPM**은 영어 CPM을 5로 나눈 값이다. 오타와 초과 입력은 정확도에는 반영되지만 속도 분자에는 들어가지 않는다. 기본 단위는 한국어 CPM과 영어 WPM이며 언어별 단위는 환경설정에서 바꾼다. 한 줄 속도도 첫 확정 입력부터 제출까지 계산한다. 설정 화면과 앱 비활성 구간은 제외하고 입력하지 않고 생각한 시간은 포함한다. 입력 중에는 정확도만 보이고, 속도는 한 줄 제출 또는 글 묶음 완료 시점에 보고한다. 1초 미만 세션 속도는 `—`로 표시한다.

한 줄·짧은 글·긴 글 세션의 통계는 줄별 표시 속도에서 유효 표본을 만든다. 20줄 이하에서는 유효 표본이 3개 이상일 때 최고·최저 한 개씩 제외한다. 20줄을 넘으면 유효 표본 수의 5%를 내림해 양쪽 끝에서 같은 수를 제외한다. 평균, 모집단 표준편차, 중간값과 P25–P75 범위를 표시한다. P25와 P75는 중간값을 먼저 구한 뒤 홀수 표본에서는 가운데 값을 제외한 두 절반의 중앙값으로 계산한다. 속도가 없는 줄은 통계에서 제외하고 전체 유효 수와 포함 수를 함께 보여주며 결과 값은 정수로 반올림한다.

하이스코어는 모드·연습 언어별이며 한 줄은 세션 문장 수도 구분한다. 정상 완료, 제출 문자 수 기준 가중 정확도 97% 이상, 유효 속도 표본 5개 이상이어야 대상이다. 첫 대상 세션은 등록한다. 기존 기록은 반올림 전 원시 속도 표본의 중간값이 0.3% 이상 향상되고, 단측 Mann–Whitney 검정에서 `p < 0.05`일 때 갱신한다. 조합 수가 100,000 이하이면 동점을 포함한 정확 순열 검정, 그보다 크면 동점 보정과 연속성 보정을 적용한 정규 근사를 쓴다. 표시 반올림은 판정에 쓰지 않는다. 판정 계산이 실패해도 정상 완료 세션을 저장하고 기존 최고 기록은 보존한다. 결과 화면은 저장 실패와 판정 실패를 구분해 알린다.

## 기록과 데이터 보호

환경설정의 최근 연습 기록은 최근 100개 세션에서 완료하고 유효한 속도 표본이 있는 세션만 모드·연습 언어·한 줄 문장 수별로 묶어 최근 속도 추이와 최근 5회 평균을 보여준다. 비교할 세션이 3회 미만인 묶음은 추이 대신 안내를 표시한다.

설정·기록은 플랫폼 웹뷰 또는 브라우저 프로필별 로컬 저장소에 저장한다. 화면 PNG와 JSON 백업은 사용자가 직접 저장을 요청할 때만 만든다. 입력 중인 원문은 기록이나 백업에 저장하지 않는다.

설정·테마 저장은 버전 1, 언어별 글꼴 저장은 버전 2, 앱 환경설정은 버전 3 스키마다. 줄별 기록·세션·하이스코어는 `tagak:history` 버전 4에 보관하고, 베네치아 기록은 독립된 `tagak:venice:records` 버전 1에 둔다. 줄별 완료 결과와 최근 세션은 각각 최대 100개다. 베네치아 기록은 최근 30회와 Top 10을 둔다. 하이스코어만 초기화하면 세션과 줄별 기록은 유지한다. 전체 기록 삭제는 줄별 기록·세션·하이스코어를 함께 지우며 확인을 요구한다.

백업 형식은 `tagak-data-backup` 버전 1이다. 환경설정, 테마·글꼴, 줄별 기록, 세션, 하이스코어와 베네치아 기록을 포함한다. 가져올 데이터는 경계에서 버전·필드를 검증한다. 기존 기록이 있으면 병합·전체 교체·취소를 고른다. 병합 시 겹치는 ID의 연습·세션 기록은 현재 데이터가 우선하고 현재 하이스코어도 유지한다. 손상되거나 지원하지 않는 데이터는 덮어쓰지 않는다. 저장 실패가 나도 결과 화면은 사용할 수 있고 기존 데이터는 보존한다.

연습 기록 v4는 구 v1–v3의 줄별 기록을 읽으며 이전 형식에 없던 세션·하이스코어는 빈 목록으로 처리한다. 환경설정 v1·v2는 새 선택지 기본값을 채워 v3으로 옮기고, 공통 글꼴 v1은 언어별 글꼴 v2로 읽는다. 검증된 이전 저장 키 데이터는 새 `tagak:*` 키로 옮긴 후 확인이 끝나면 정리한다. 손상되거나 지원하지 않는 원본 값은 자동으로 덮어쓰지 않는다. 브라우저 origin이 달라지면 브라우저 저장소가 분리되어 자동으로 옮겨지지 않으므로 기기를 바꾸거나 앱을 재설치하기 전에 환경설정에서 JSON 백업을 만든다.

모드별 출처와 라이선스는 [연습 자료 인벤토리](../TEXT-LICENSES.md)와 앱의 오프라인 저작권·제3자 고지에서 확인한다. 타각 소프트웨어와 타각이 직접 작성한 자료의 라이선스 범위는 [RIGHTS.md](../RIGHTS.md)에 있다.
