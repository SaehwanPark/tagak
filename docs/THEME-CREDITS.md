# 색상 테마 크레딧

14개 테마의 색은 `src/ui/styles.css`에 CSS 값으로 정의한다. 아래 외부 프로젝트는 색상 팔레트의 참고 출처이며, 타각은 공식 포트가 아니고 원 프로젝트의 후원·승인을 암시하지 않는다. 코드, 이미지, 폰트, 아이콘은 가져오지 않았다. 참조 팔레트는 타각의 16개 화면 토큰에 맞춰 조정했으며 대비 확인 결과를 자동 테스트한다.

| 타각 테마 | 참고 프로젝트 | 라이선스 |
| --- | --- | --- |
| Catppuccin Mocha · Catppuccin Latte | [Catppuccin palette](https://github.com/catppuccin/catppuccin) | [MIT](https://github.com/catppuccin/catppuccin/blob/main/LICENSE) |
| Tokyo Night | [Tokyo Night VS Code theme](https://github.com/tokyo-night/tokyo-night-vscode-theme) | [MIT](https://github.com/tokyo-night/tokyo-night-vscode-theme/blob/master/LICENSE.txt) |
| Nord · Nord Light | [Nord](https://github.com/nordtheme/nord) | [MIT](https://github.com/nordtheme/nord/blob/develop/license) |
| Gruvbox | [Gruvbox](https://github.com/morhetz/gruvbox) | MIT/X11 (프로젝트 저장소의 라이선스 표기) |
| Dracula | [Dracula theme](https://github.com/dracula/dracula-theme) | [MIT](https://github.com/dracula/dracula-theme/blob/master/LICENSE) |
| Rosé Pine | [Rosé Pine theme](https://github.com/rose-pine/rose-pine-theme) | [MIT](https://github.com/rose-pine/rose-pine-theme/blob/main/LICENSE) |
| Solarized Light | [Solarized](https://github.com/altercation/solarized) | [MIT](https://github.com/altercation/solarized/blob/master/LICENSE) |

`Terminal Night`와 `Paper Light`는 타각의 기존 팔레트다. Serika Dark와 Modern Dolch는 [Monkeytype](https://github.com/monkeytypegame/monkeytype)의 GPL-3.0 저장소에 속하므로 같은 이름으로 포팅하지 않았다. `Amber Terminal`과 `Slate Mint`는 타각에서 다시 정한 이름과 팔레트다. `Retro CRT`도 제품 포트라는 인상을 피하도록 `Phosphor Green`으로 이름과 팔레트를 조정했다. 이 세 테마는 특정 제품의 공식 스킨으로 제공하지 않는다. 화면에서 쓰는 정확도·오타 표시는 색상과 별도의 밑줄을 함께 사용한다.

이전 타각 버전은 신규 테마 ID를 모른다. 해당 버전에서는 기본 테마를 보여주고 알 수 없는 저장값을 덮어쓰지 않으므로, 새 ID를 바꾸려면 현재 버전을 사용한다.
