# 플랫폼 검증표

현재 개발 기준은 **Windows 11 + Chrome**이다. 이 환경에서 설치·빌드·실행 또는 기본 한글 연습을 막는 치명적 문제가 재현된 경우에만 현재 개발을 멈춘다. 검증 도구의 한계나 확인되지 않은 항목은 실패가 아닌 증거 공백으로 기록한다.

| 환경 | 확인한 내용 | 남은 확인 |
| --- | --- | --- |
| **Windows 11 · Chrome (현재 기준)** | Windows 호스트 Node 26.13.0 / npm 12.2.0에서 엄격한 `npm ci`, `npm run build`, `node serve.mjs`와 루프백 HTTP 200을 확인했다. Chrome의 기본 한글 연습, 다음 문장, 점수와 메뉴 복귀도 확인했다. 2026-11-18 사용자 수동 감사에서 실제 Microsoft 한국어 IME 조합, Backspace 수정, 조합 확정 Enter와 제출 Enter 구분, 새 프로필의 오프라인 연습, 200% 확대, A10 테마와 A11 글꼴을 모두 정상 확인했다고 보고했다. 자동화와 확장 입력은 실제 OS 입력기를 대신하지 않는다. | A17은 IME Space 이벤트 처리를 변경했으나 이 변경 이후 Windows Chrome의 수동 회귀 확인은 하지 않았다. A18 설정 조작과 브라우저 탭 복귀 후 입력 재개는 제어 브라우저에서 확인했으나 실제 Windows Chrome의 Alt+Tab 복귀는 확인하지 못했다. A30 베네치아의 Space/Enter 분리도 합성 IME 이벤트로만 확인했으며 실제 Microsoft 한국어 IME에서 게임 낱말 조합·확정·제출은 아직 수동 확인하지 않았다. 컴퓨터 제어 도구가 로컬 URL 허용을 확인하지 못해 검증을 중단했던 이력은 실패 재현이 아닌 증거 공백이다. Windows Edge와 macOS Safari는 별도의 후속 호환성 범위다. |
| macOS · Playwright Chromium (A30 자동화) | 2026-11-22 `npm run verify` 통과: Vitest 14개 파일 82개 테스트, 프로덕션 빌드, Playwright 55개. 키보드 시작 레벨, 점수·Top 10, 추천·레벨 변경, 14레벨 목표, 레벨별 단어 후보 수·타수 분포, 200% 확대, 합성 IME와 Space/Enter 분리, 붙여넣기·드롭 차단, 설정·탭 비활성화 중 정지/복귀, 효과음 on/off, PNG 다운로드, 손상 저장값 보존과 결과 표시를 확인했다. 첫 낱말 생성 시각도 페이지가 열린 뒤 비영 시각에서 확인했다. | macOS 실제 입력기나 Windows 11을 대상으로 한 검증이 아니다. 실제 Microsoft 한국어 IME 테스트와 시작 레벨·상위 레벨의 사람 체감 밸런스 확인이 남았다. |
| macOS Tahoe · Chrome 157 (이슈 범위 확인) | 이슈 #23의 사전 수정 재현은 기본 한국어 두벌식 입력기에서 조합 중 Space 한 번이 두 칸 공백을 남기는 것이었다. 2026-11-18 사용자 실제 입력기 확인에서 수정 후 `한글을` 뒤 Space 한 번이 공백 하나만 남기고, 제시문 완료 뒤 Space 한 번이 한 단계만 이동하는 것을 확인했다. 이슈 #24의 두 상단 버튼 위쪽 좌표도 각각 95.3 CSS px로 맞는 것을 확인했다. | 이번 검증은 이슈 #23의 IME 흐름과 #24의 연습 화면 정렬에 한정한다. Windows Chrome 기준 환경은 아니며 macOS 전체 호환성 또는 Safari 확인을 뜻하지 않는다. |
| Windows 11 · Edge (후속) | 확장 탭에서 로컬 배포물과 연습 입력창을 열었다. | Edge 호환성은 현재 기준이 아니다. |
| macOS · Safari (후속) | 실제 macOS 런타임 검증 전. 사용자 로그에서 npm 12.2.0 `npm ci`는 완료됐지만 잠금 파일의 macOS 전용 선택 의존성 `fsevents@2.3.3` 설치 스크립트가 차단됐다는 경고가 있었다. 프로젝트는 이 잠긴 버전만 `allowScripts`에서 승인한다. | macOS 설치·빌드와 Safari·한국어 IME 호환성. 승인 설정은 경고 원인을 다루며 macOS 앱 검증을 뜻하지 않는다. |
| Ubuntu · Firefox · IBus 한글 두벌식 (보조) | 실제 조합, Backspace, 조합 확정과 제출용 Enter, Esc 메뉴 복귀, 브라우저 200% 확대를 확인했다. Chromium·Firefox·WebKit 배포물 자동 확인도 마쳤다. | 보조 환경 증거로 유지한다. |

Playwright의 `CompositionEvent` 테스트는 앱이 합성 IME 이벤트 순서를 처리하는지 확인한다. 운영체제의 실제 입력기를 구동하는 검증으로 간주하지 않는다.

기준 환경의 재현 절차와 완료 상태는 [실행 체크리스트](SPEC.md)의 A06 항목에 기록한다. 자유 입력 연습(A08)은 점수나 앱 저장 데이터를 만들지 않는다. A09는 사용자가 직접 저장을 요청했을 때만 입력이 이미지 파일에 포함된다.
