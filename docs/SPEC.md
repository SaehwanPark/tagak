# SPEC

현재 버전은 `v0.19.0`이다. 제품의 동작과 기술 결정은 [프로젝트 명세](PROJECT-SPEC.md)를 따른다. 사용자 안내는 [README](../README.md), 구조는 [ARCHITECTURE](../ARCHITECTURE.md), 버전별 변경은 [CHANGELOG](../CHANGELOG.md)에 있다.

## 상태 표시

- 체크된 항목은 구현을 마치고 완료 조건을 확인한 작업이다.
- 현재 구현 중인 사용자 기능 슬라이스에 [지금 구현중]을 붙인다. 완료 후 체크하고 레이블을 뗀다.
- 선행 작업과 완료 조건이 정해진 다음 한 항목에 [바로 다음에 구현해야 함]을 붙인다.
- 플랫폼 검증의 미확인 항목은 별도의 비차단 후속으로 관리한다. macOS 14+ Tauri 앱의 설치·실행 또는 기본 한글 연습을 막는 치명적 문제가 재현된 경우에만 현재 개발을 멈춘다.

  - 유지한 검증: 실제 IME와 구분한 합성 IME 이벤트 순서, 한국어 문자소·두벌식 타수·속도 계산, 여러 탭 동시 기록 저장과 실패 보존, 구버전 마이그레이션, 5줄 묶음 및 완료 효과음 경계, CSS 글꼴 계약, `TEXT-LICENSES.md` 일치 검증은 줄이거나 약화하지 않았다.
  - `npm run verify` 통과: Vitest 10개 파일 38개 테스트, 프로덕션 빌드, Playwright E2E 41개. 초점 복구·환경설정 왕복·기록 흐름 회귀와 가상 시계 기반 WPM 검증을 확인했다. Windows 11 + Chrome 수동 확인은 이 변경에서 수행하지 않았다.

## 호환성 후속 (개발 비차단)
- A31은 macOS 14+ Tauri/WebKit 기준을 확정했다. A32에서 Windows 11 Tauri/WebView2 데스크톱 지원을 별도로 추가한다. Windows 11 + Chrome의 브라우저 검증은 네이티브 앱 검증을 대신하지 않으며, Linux·Windows Edge·macOS Safari는 이 슬라이스의 지원 선언 범위가 아니다.
