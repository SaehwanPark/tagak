# Changelog

Changes users can see are recorded here. Development history before v1.0.0 remains in the [v1.0.0 tagged changelog](https://github.com/SaehwanPark/tagak/blob/v1.0.0/CHANGELOG.md).

## [Unreleased]

### Added

- Show a recent speed trend and recent-five-session average for comparable practice sessions in the local history screen.
- Start a random short or long passage, or the most recently practiced matching passage, directly from the passage list.

### Changed

- Publish an English project landing page with a Korean counterpart and a separate user guide.
- Adopt Apache-2.0 for Tagak-owned source, documentation, and original content. Keep third-party text, dependencies, and theme credits under their listed terms.

## [1.0.0] - 2026-11-26

### Added

- First public release for macOS 14+ Apple Silicon and Windows 11 x64, with one-line, short-passage, and long-passage practice, two Korean word games, themes, local records, and JSON backup/import.

### Changed

- Added installation guidance, actual app screenshots, and third-party content credits. Replaced practice text whose usage permission could not be established.
